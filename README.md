# SisuReplicateGrid
## Installation
### Step 1: Download the File
Download the SISU.html file from this repository to your computer.

### Step 2: Open in Browser
Locate the downloaded file and double-click it, or right-click and select Open with, then choose your preferred web browser (e.g., Chrome, Firefox, or Edge).

## Background Information
I created a UI/UX replica of the SISU calendar page using only the grid. The CSS, HTML and JS are all in the same file. Flexbox would be easier and preferred for certain sections, but due to the challenge of using grids only. I took a few creative liberties regarding the calendar entries' colour scheme to improve the feel of the website.
